# Contributing to Powder Compass

Welcome — especially if this is one of your first open-source contributions.

## Easy ways to help

- Open an Issue with a scoring suggestion, bug report, or clearer wording.
- Add a test for a scoring edge case.
- Improve the documentation, or translate a verdict.
- Open a Pull Request for a small, focused change.

## Ground rules

1. Keep changes small enough to explain in a few sentences.
2. Run `cargo test` before opening a Pull Request.
3. Be kind and specific in discussion.
4. Please discuss in an Issue before adding a new dependency (crate) —
   version 1 is intentionally dependency-free.
5. Powder Compass is a playful planning helper. Its score is not an
   official safety or avalanche assessment.
